components under other terms). See <https://dftbplus.org>.

repository, and this repository ships none. Each set on
<https://dftb.org/parameters> carries its own licence, usually free for academic
use, sometimes requiring registration, and generally requiring citation. Read
and accept the licence of the set you download.
